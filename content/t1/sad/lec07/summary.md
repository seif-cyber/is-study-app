## ⚡ ملخص SAD Lec 7: Modelling & OO Concepts

- **Software process:** Specification · Design & implementation · Validation · Maintenance & evolution.
- **Model** = abstraction · ليه: تقليل التعقيد · اختبار قبل البناء · تواصل · توثيق.
- **UML:** Functional (use case) · Static (class, object, package) · Dynamic (interaction, state, activity). أدوات: Rational Rose · Bouml · Visio.
- **OO:** الوحدة = **object** (state + behavior) · نبني حوالين objects مش functions.
- **الخصائص:** Identity · Classification · Encapsulation · Abstraction · Inheritance · Polymorphism · Generics · Cohesion · Coupling.
- **Identity:** كل object مميز (memory address) · **Classification:** نفس attributes/operations = نفس class.
- **Abstraction:** الغرض بيحدد المهم · **Encapsulation:** data hiding + implementation hiding.
- **Inheritance:** parent/base ← child/derived · general ثم special · **Polymorphism:** نفس operation بـ methods مختلفة (getArea).
- **Generics:** type وقت التشغيل.
- **Class notation:** name · attributes · operations · مفقود ≠ فاضي · `-` private · `+` public · **operation vs method**.
- **مثال الرحلات:** City · Airport · Airline · Flight · Passenger · Seat · Plane · Pilot.
