# الحل البياني — Sheet 2 (Graphical Solution Problems)

> [!NOTE]
> الشيت ده فيه **7 موديلات LP جاهزة** (نفس موديلات مسائل Sheet 1)، والمطلوب **حلها بالـ graphical analysis**. لكل موديل هنا: **نقاط الخطوط، تقاطعات الـ corner points، وجدول قيم Z** والحل الأمثل. (الحسابات كلها بالكسور وراجعتها بـ solver.)

## طريقة الحل البياني (تذكير)
1. حوّل كل قيد لمعادلة وارسم الخط (نقطتين: X₁=0 ثم X₂=0). 2. حدد **feasible region** (الجانب الصح لكل قيد). 3. اكتب **corner points** (تقاطعات الخطوط). 4. احسب **Z** عند كل corner. 5. **الأكبر (Max)** أو **الأصغر (Min)** هو الأمثل.

---
## موديل 1

```
Max Z = 6X₁ + 4X₂
s.t.
10X₁ + 10X₂ ≤ 100
7X₁ + 3X₂ ≤ 42
X₁, X₂ ≥ 0
```

**الخطوط:** نقاط القيود: 10X₁+10X₂=100 ← (10,0),(0,10) · 7X₁+3X₂=42 ← (6,0),(0,14). التقاطع: X₁+X₂=10 مع 7X₁+3X₂=42 ⇒ X₁=3, X₂=7.

| Corner point (x₁, x₂) | Z |
|---|---|
| (0, 0) | 0 |
| (0, 10) | 40 |
| (3, 7) | 46 ← **optimal** |
| (6, 0) | 36 |

---

## موديل 2

```
Max Z = 50X₁ + 40X₂
s.t.
3X₁ + 5X₂ ≤ 150
10X₁ + 4X₂ ≤ 200
X₁, X₂ ≥ 0
```

**الخطوط:** 3X₁+5X₂=150 ← (50,0),(0,30) · 10X₁+4X₂=200 ← (20,0),(0,50). التقاطع: X₁=200/19, X₂=450/19.

| Corner point (x₁, x₂) | Z |
|---|---|
| (0, 0) | 0 |
| (0, 30) | 1200 |
| (200/19 ≈ 10.53, 450/19 ≈ 23.68) | 28000/19 ≈ 1473.684 ← **optimal** |
| (20, 0) | 1000 |

---

## موديل 3

```
Min Z = 3X₁ + 5X₂
s.t.
10X₁ + 2X₂ ≥ 20
6X₁ + 6X₂ ≥ 36
X₂ ≥ 2
X₁, X₂ ≥ 0
```

**الخطوط:** 10X₁+2X₂=20 ← (2,0),(0,10) · X₁+X₂=6 ← (6,0),(0,6) · X₂=2. المنطقة **unbounded** (فوق الخطوط) لكن min بيكون عند corner point.

| Corner point (x₁, x₂) | Z |
|---|---|
| (0, 10) | 50 |
| (1, 5) | 28 |
| (4, 2) | 22 ← **optimal** |

---

## موديل 4

```
Max Z = 400X₁ + 100X₂
s.t.
8X₁ + 10X₂ ≤ 80
2X₁ + 6X₂ ≤ 36
X₁ ≤ 6
X₁, X₂ ≥ 0
```

**الخطوط:** 8X₁+10X₂=80 ← (10,0),(0,8) · 2X₁+6X₂=36 ← (18,0),(0,6) · X₁=6. التقاطع: X₁=6 مع 8X₁+10X₂=80 ⇒ X₂=3.2.

| Corner point (x₁, x₂) | Z |
|---|---|
| (0, 0) | 0 |
| (0, 6) | 600 |
| (30/7 ≈ 4.29, 32/7 ≈ 4.57) | 15200/7 ≈ 2171.429 |
| (6, 0) | 2400 |
| (6, 16/5 ≈ 3.20) | 2720 ← **optimal** |

---

## موديل 5

```
Max Z = X₁ + 5X₂
s.t.
5X₁ + 5X₂ ≤ 25
2X₁ + 4X₂ ≤ 16
X₁ ≤ 5
X₁, X₂ ≥ 0
```

**الخطوط:** X₁+X₂=5 ← (5,0),(0,5) · X₁+2X₂=8 ← (8,0),(0,4) · X₁=5. الحل (0,4) على قيد السكر.

| Corner point (x₁, x₂) | Z |
|---|---|
| (0, 0) | 0 |
| (0, 4) | 20 ← **optimal** |
| (2, 3) | 17 |
| (5, 0) | 5 |

---

## موديل 6

```
Max Z = 300X₁ + 400X₂
s.t.
3X₁ + 2X₂ ≤ 18
2X₁ + 4X₂ ≤ 20
X₂ ≤ 4
X₁, X₂ ≥ 0
```

**الخطوط:** 3X₁+2X₂=18 ← (6,0),(0,9) · X₁+2X₂=10 ← (10,0),(0,5) · X₂=4. التقاطع: X₁=4, X₂=3.

| Corner point (x₁, x₂) | Z |
|---|---|
| (0, 0) | 0 |
| (0, 4) | 1600 |
| (2, 4) | 2200 |
| (4, 3) | 2400 ← **optimal** |
| (6, 0) | 1800 |

## موديل 7

```
Min Z = 0.05X₁ + 0.03X₂
s.t.
8X₁ + 6X₂ ≥ 48
X₁ + 2X₂ ≥ 12
X₁, X₂ ≥ 0
```

**الخطوط:** 8X₁+6X₂=48 ← (6,0),(0,8) · X₁+2X₂=12 ← (12,0),(0,6). التقاطع: X₁=12/5=2.4, X₂=24/5=4.8.

| Corner point (x₁, x₂) | Z |
|---|---|
| (0, 8) | 6/25 ≈ 0.24 ← **optimal** |
| (12/5 ≈ 2.40, 24/5 ≈ 4.80) | 33/125 ≈ 0.264 |
| (12, 0) | 3/5 ≈ 0.6 |

---

> [!EXAM]
> **النتائج:** 1) (3,7) ⇒ 46 · 2) (200/19, 450/19) ⇒ 28000/19 ≈ 1473.68 · 3) (4,2) ⇒ 22 (Min) · 4) (6, 3.2) ⇒ 2720 · 5) (0,4) ⇒ 20 · 6) (4,3) ⇒ 2400 · 7) (0,8) ⇒ 0.24 (Min).
