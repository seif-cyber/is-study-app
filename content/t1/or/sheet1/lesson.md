# صياغة الموديلات والحل البياني — Sheet 1: Linear Programming: Model Formulation and Graphical Solution

> [!NOTE]
> الشيت ده فيه **7 مسائل كلام (word problems)**؛ المطلوب في كل واحدة: **(a) صياغة موديل LP** و **(b) الحل بالـ graphical analysis**. هنا لكل مسألة: **متغيرات القرار + دالة الهدف + القيود + الحل الأمثل** (راجعت كل الحلول بحساب كل الـ corner points وبـ solver). الـ corner points بالتفصيل في **Sheet 2**.

> [!WARNING]
> ملف الشيت ده وملف Sheet 2 الاتنين مكتوب عليهم "**Sheet -2**". الأول (ده) هو المسائل الكلامية، والتاني هو نفس الموديلات جاهزة للحل البياني.

## خطوات الصياغة (تذكير)
1. **عرّف متغيرات القرار** (x₁, x₂). 2. **دالة الهدف** (Max ربح / Min تكلفة). 3. **القيود** من الموارد أو الحدود الدنيا. 4. **x ≥ 0**.

---
## مسألة 1: Product 1 / Product 2 (assembly lines)

شركة بتنتج منتجين على خطي تجميع. خط 1 متاح **100 ساعة**، خط 2 متاح **42 ساعة**. كل منتج يحتاج **10 ساعات** على خط 1. على خط 2: منتج 1 **7 ساعات** ومنتج 2 **3 ساعات**. ربح منتج 1 = **6$** ومنتج 2 = **4$**.

**(a) الموديل:**
- **متغيرات القرار:** x₁ = وحدات المنتج 1 · x₂ = وحدات المنتج 2
- **دالة الهدف:** `Max Z = 6x₁ + 4x₂`
- **القيود:**
```
10x₁ + 10x₂ ≤ 100   (assembly line 1)
7x₁ + 3x₂ ≤ 42      (assembly line 2)
 x₁, x₂ ≥ 0
```

**(b) الحل البياني:** **x₁ = 3، x₂ = 7، Z = 46$**

> ملاحظة: 10(3)+10(7) = 100 ✓ · 7(3)+3(7) = 42 ✓ (القيدين binding)

## مسألة 2: Clothier: coats & slacks

صانع ملابس بيعمل **معاطف (coats)** و**بناطيل (slacks)**. المتاح **150 ياردة صوف** و **200 ساعة عمل**. المعطف: **3 ياردة صوف و 10 ساعات**. البنطلون: **5 ياردة و 4 ساعات**. ربح المعطف **50$** والبنطلون **40$**.

**(a) الموديل:**
- **متغيرات القرار:** x₁ = عدد المعاطف · x₂ = عدد البناطيل
- **دالة الهدف:** `Max Z = 50x₁ + 40x₂`
- **القيود:**
```
3x₁ + 5x₂ ≤ 150   (wool, sq. yd)
10x₁ + 4x₂ ≤ 200  (labor, hours)
 x₁, x₂ ≥ 0
```

**(b) الحل البياني:** **x₁ = 200/19 ≈ 10.53، x₂ = 450/19 ≈ 23.68، Z = 28000/19 ≈ 1473.68$**

> ملاحظة: الحل كسري؛ لو المطلوب **أعداد صحيحة** نحتاج integer programming (التقريب للأقرب مش مضمون إنه الأمثل)

## مسألة 3: Kalo Fertilizer

شركة بتعمل سماد من مادتين. **رطل المادة 1** فيه **10 أونصة nitrogen** و**6 أونصة phosphate**. **رطل المادة 2** فيه **2 nitrogen** و**6 phosphate** و**1 potassium**. تكلفة المادة 1 = **3$/رطل** والمادة 2 = **5$/رطل**. المطلوب كيس سماد بـ **حد أدنى 20 أونصة nitrogen و 36 phosphate و 2 potassium** بأقل تكلفة.

**(a) الموديل:**
- **متغيرات القرار:** x₁ = أرطال المادة 1 · x₂ = أرطال المادة 2
- **دالة الهدف:** `Min Z = 3x₁ + 5x₂`
- **القيود:**
```
10x₁ + 2x₂ ≥ 20   (nitrogen)
6x₁ + 6x₂ ≥ 36    (phosphate)
 x₂ ≥ 2           (potassium)
 x₁, x₂ ≥ 0
```

**(b) الحل البياني:** **x₁ = 4، x₂ = 2، Z = 22$**

> ملاحظة: الـ potassium موجود في المادة 2 بس (1 أونصة/رطل) فالقيد x₂ ≥ 2

## مسألة 4: Pinewood Furniture

شركة بتصنع **كراسي** و**ترابيزات** من **العمل (80 ساعة)** و**الخشب (36 board-ft)** يوميًا. طلب الكراسي **لا يزيد عن 6** يوميًا. الكرسي: **8 ساعات عمل و 2 board-ft**. الترابيزة: **10 ساعات و 6 board-ft**. ربح الكرسي **400$** والترابيزة **100$**.

**(a) الموديل:**
- **متغيرات القرار:** x₁ = كراسي · x₂ = ترابيزات
- **دالة الهدف:** `Max Z = 400x₁ + 100x₂`
- **القيود:**
```
8x₁ + 10x₂ ≤ 80   (labor)
2x₁ + 6x₂ ≤ 36    (wood)
 x₁ ≤ 6           (chair demand)
 x₁, x₂ ≥ 0
```

**(b) الحل البياني:** **x₁ = 6، x₂ = 3.2، Z = 2720$**

> ملاحظة: 8(6)+10(3.2) = 80 ✓ (labor مستنفد) · 2(6)+6(3.2) = 31.2 ≤ 36 (فيه slack 4.8 في الخشب)

## مسألة 5: Crumb and Custard Bakery

مخبز بيعمل **coffee cakes** و **Danish pastries** في صواني. المتاح **25 رطل دقيق** و**16 رطل سكر**، وطلب coffee cakes **5** صواني. صينية coffee cake: **5 دقيق و 2 سكر**، وصينية Danish: **5 دقيق و 4 سكر**. ربح coffee cake **1$** و Danish **5$**.

**(a) الموديل:**
- **متغيرات القرار:** x₁ = صواني coffee cakes · x₂ = صواني Danish
- **دالة الهدف:** `Max Z = x₁ + 5x₂`
- **القيود:**
```
5x₁ + 5x₂ ≤ 25   (flour)
2x₁ + 4x₂ ≤ 16   (sugar)
 x₁ ≤ 5          (demand)
 x₁, x₂ ≥ 0
```

**(b) الحل البياني:** **x₁ = 0، x₂ = 4، Z = 20$**

> ملاحظة: الدقيق: 5(4) = 20 ≤ 25 · السكر: 4(4) = 16 ✓ (binding) · الـ Danish أربح بكتير فبيستبعد coffee cakes

## مسألة 6: Jewelry store

محل مجوهرات بيعمل **عقود (necklaces)** و**أساور (bracelets)** من **18 أونصة ذهب** و**20 أونصة بلاتين**. العقد: **3 ذهب و 2 بلاتين**. السوار: **2 ذهب و 4 بلاتين**. طلب الأساور **لا يزيد عن 4**. ربح العقد **300$** والسوار **400$**.

**(a) الموديل:**
- **متغيرات القرار:** x₁ = عقود · x₂ = أساور
- **دالة الهدف:** `Max Z = 300x₁ + 400x₂`
- **القيود:**
```
3x₁ + 2x₂ ≤ 18   (gold)
2x₁ + 4x₂ ≤ 20   (platinum)
 x₂ ≤ 4          (bracelet demand)
 x₁, x₂ ≥ 0
```

**(b) الحل البياني:** **x₁ = 4، x₂ = 3، Z = 2400$**

> ملاحظة: 3(4)+2(3) = 18 ✓ · 2(4)+4(3) = 20 ✓ (القيدين binding)

## مسألة 7: Munchies Cereal

شركة بتعمل cereal من **oats** و **rice** اللي بيدوا فيتامين A و B. المطلوب في العلبة **حد أدنى 48 mg فيتامين A و 12 mg فيتامين B** بأقل تكلفة. أونصة oats: **8 mg A و 1 mg B** وتكلفتها **0.05$**. أونصة rice: **6 mg A و 2 mg B** وتكلفتها **0.03$**.

**(a) الموديل:**
- **متغيرات القرار:** x₁ = أونصات oats · x₂ = أونصات rice
- **دالة الهدف:** `Min Z = 0.05x₁ + 0.03x₂`
- **القيود:**
```
8x₁ + 6x₂ ≥ 48   (vitamin A)
 x₁ + 2x₂ ≥ 12   (vitamin B)
 x₁, x₂ ≥ 0
```

**(b) الحل البياني:** **x₁ = 0، x₂ = 8، Z = 0.24$**

> ملاحظة: 6(8) = 48 ✓ و 2(8) = 16 ≥ 12 ✓

> [!EXAM]
> الأنماط: **Max (موارد ≤)**: 1، 2، 4، 5، 6 · **Min (حدود دنيا ≥)**: 3 و 7. ودايمًا الحل عند **corner point**. القيود البسيطة زي x₁ ≤ 6 (طلب) بتتحط كقيد برضه.
