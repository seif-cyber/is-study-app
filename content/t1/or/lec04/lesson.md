## 1. الحالات الخاصة في السمبلكس — Special Cases

### 1.1 Degeneracy (التحلل)

> **Degenerate solution** = حل فيه **متغير أساسي (basic variable) قيمته = صفر**. بيحصل لما يبقى فيه **تعادل (tie) في الـ minimum ratio test**.

**مثال:** Max z = 3x₁ + 9x₂ ، s.t. x₁ + 4x₂ ≤ 8 ، x₁ + 2x₂ ≤ 4 ، x₁, x₂ ≥ 0.

| Iteration | Basic | x₁ | x₂ | x₃ | x₄ | RHS |
|---|---|---|---|---|---|---|
| 0 | z | −3 | **−9** | 0 | 0 | 0 |
| (x₂ enters, **x₃ leaves**) | x₃ | 1 | 4 | 1 | 0 | 8 |
| | x₄ | 1 | 2 | 0 | 1 | 4 |
| 1 | z | −3/4 | 0 | 9/4 | 0 | 18 |
| (x₁ enters, **x₄ leaves**) | x₂ | 1/4 | 1 | 1/4 | 0 | 2 |
| | **x₄** | 1/2 | 0 | −1/2 | 1 | **0** |
| 2 (optimum) | z | 0 | 0 | 3/2 | 3/2 | 18 |
| | x₂ | 0 | 1 | 1/2 | −1/2 | 2 |
| | x₁ | 1 | 0 | −1 | 2 | **0** |

- في أول iteration النسب **8/4 = 2** و **4/2 = 2** (**tie**)، فالـ basic variable التانية (x₄) بقت **= 0** ← **degenerate**.
- النتيجة: **z = 18 عند (0, 2)** والـ iteration التانية **ما حسّنتش z** (18 → 18).

> [!WARNING]
> الـ degeneracy ممكن نظريًا يسبب **cycling** (الدوران في نفس الـ bases) لكن نادرًا في التطبيق.

### 1.2 Alternative Optima

> لو **صف z في الجدول الأمثل فيه معامل = 0 لمتغير non-basic** ⇒ **فيه حل أمثل بديل**، ندخل المتغير ده ونحصل على حل تاني بنفس z.

**مثال:** Max z = 2x₁ + 4x₂ ، s.t. x₁ + 2x₂ ≤ 5 ، x₁ + x₂ ≤ 4.

| Iter | Basic | x₁ | x₂ | x₃ | x₄ | RHS |
|---|---|---|---|---|---|---|
| 1 (optimum) | z | **0** | 0 | 2 | 0 | **10** |
| | x₂ | 1/2 | 1 | 1/2 | 0 | 5/2 |
| | x₄ | 1/2 | 0 | −1/2 | 1 | 3/2 |
| 2 (alternative optimum, x₁ enters) | z | 0 | 0 | 2 | 0 | **10** |
| | x₂ | 0 | 1 | 1 | −1 | 1 |
| | x₁ | 1 | 0 | −1 | 2 | 3 |

- الحل الأول: **(0, 5/2)**، الحل البديل: **(3, 1)**، وكلاهما **z = 10**؛ وكل نقطة على الخط بينهم optimal. (السبب: دالة الهدف **2x₁+4x₂ = 2(x₁+2x₂)** موازية للقيد الأول.)

### 1.3 Unbounded Solutions

> **Unbounded** = في عمود entering variable **كل معاملات القيود ≤ 0** (مفيش نسبة موجبة) ⇒ **مفيش leaving variable** ⇒ Z بتزيد بلا حد.

**مثال:** Max z = 2x₁ + x₂ ، s.t. x₁ − x₂ ≤ 10 ، 2x₁ ≤ 40.

| Basic | x₁ | x₂ | x₃ | x₄ | RHS |
|---|---|---|---|---|---|
| z | −2 | −1 | 0 | 0 | 0 |
| x₃ | 1 | **−1** | 1 | 0 | 10 |
| x₄ | 2 | **0** | 0 | 1 | 40 |

عمود x₂ = (−1, 0): **ماينفعش نحسب leaving variable** ⇒ **Unbounded objective value**.

### 1.4 Infeasible (Non-existing) Solutions

> **Infeasible** = المسألة **مفيش لها حل ممكن**. في السمبلكس (طريقة **Big-M**) بتظهر لما **الحل "الأمثل" لسه فيه artificial variable بقيمة موجبة (> 0)** (pseudo-optimum).

**مثال:** Max z = 3x₁ + 2x₂ ، s.t. 2x₁ + x₂ ≤ 2 ، 3x₁ + 4x₂ ≥ 12.

| Iteration | Basic | x₁ | x₂ | x₃ | x₄ | R | RHS |
|---|---|---|---|---|---|---|---|
| 1 (pseudo-optimum) | x₂ | 2 | 1 | 1 | 0 | 0 | 2 |
| | **R** | −5 | 0 | −4 | −1 | 1 | **4** |

الـ artificial **R = 4 > 0** عند "الأمثل" ⇒ **المسألة infeasible**.

| الحالة | العلامة في السمبلكس |
|---|---|
| **Degeneracy** | **tie** في الـ ratio test ⇒ basic variable = 0 |
| **Alternative optima** | معامل **0** لـ non-basic في صف z الأمثل |
| **Unbounded** | عمود الـ entering **كله ≤ 0** |
| **Infeasible** | artificial variable **> 0** في الحل النهائي |

## 2. الـ Duality — Primal و Dual

> المسألة الأصلية = **PRIMAL**. والمسألة اللي بنحصل عليها بـ **تبديل (transpose) الصفوف بالأعمدة** وليها **نفس الحل الأمثل** = **DUAL**.

**قواعد بناء الـ Dual:**
| Primal | Dual |
|---|---|
| **Max** | **Min** (والعكس) |
| معاملات دالة الهدف (c) | تبقى **RHS** للقيود |
| **RHS** (b) | تبقى معاملات دالة الهدف |
| عمود (متغير) | **صف (قيد)** |
| قيد ≤ (في Max) | متغير dual ≥ 0 |
| عدد المتغيرات **n** | عدد قيود الـ dual **= n** |
| عدد القيود **m** | عدد متغيرات الـ dual **= m** |

### مثال 1: Dual لمسألة Minimization

![شكل 1: Dual لمسألة Min](img/or/lec04/dual-min.webp)

```
Primal: Min Z = 5X1 + 8X2 + 4X3
  2X1 + 3X2 - X3 >= 10
   X1 +  X2 + 3X3 >= 5
  2X1 + 5X2 - 2X3 <= 7      (n = 3 variables, m = 5 constraints)
  3X1 -  X2 + 3X3 >= 9
   X1 + 5X2        >= 6
```
قيد الـ ≤ نحوله لـ ≥ بضرب **−1**: −2X₁ − 5X₂ + 2X₃ ≥ −7. ثم:

```
Dual: Max Z* = 10Y1 + 5Y2 - 7Y3 + 9Y4 + 6Y5
  2Y1 +  Y2 - 2Y3 + 3Y4 +  Y5 <= 5
  3Y1 +  Y2 - 5Y3 -  Y4 + 5Y5 <= 8
  -Y1 + 3Y2 + 2Y3 + 3Y4       <= 4
  Y1..Y5 >= 0
```

### مثال 2: Dual لمسألة Maximization

![شكل 2: Dual لمسألة Max](img/or/lec04/dual-max.webp)

```
Primal: Max Z = 3X1 + 5X2        (n = 2, m = 4)
  2X1 + 6X2 <= 50
  3X1 + 2X2 <= 35
  5X1 - 3X2 <= 10
        X2  <= 20
Dual:  Min Z* = 50Y1 + 35Y2 + 10Y3 + 20Y4
  2Y1 + 3Y2 + 5Y3        >= 3
  6Y1 + 2Y2 - 3Y3 +  Y4  >= 5
  Y1..Y4 >= 0
```

> [!WARNING]
> **خطأ في السلايد:** في حل المثال 2 القيد التاني مكتوب `6Y1 + 2Y2 − 3Y3 ≥ 5` وناقص حد **+ Y4** (X₂ ≤ 20 ليه معامل 1 في العمود X₂)، والمدرّس كاتب بقلم أحمر "+X₂" للتصحيح. الصح: **6Y₁ + 2Y₂ − 3Y₃ + Y₄ ≥ 5**.

## 3. تحليل الحساسية — Sensitivity Analysis

> **Sensitivity analysis** = دراسة **تأثير تغيير معاملات الموديل** على الحل الأمثل. بتجاوب على:
> 1. إزاي تغيير **RHS** قيد يأثر على الحل الأمثل؟
> 2. إزاي تغيير معامل في **دالة الهدف** يأثر؟
> 3. إزاي تغيير معامل متغير القرار في **القيود** يأثر؟

### تغيير الـ RHS — Changes in RHS of constraints

![شكل 3: جدول الحل الأمثل والتغيير في الـ RHS](img/or/lec04/sensitivity.webp)

**المثال:** Max Z = 30X₁ + 50X₂ ، s.t. 2X₁ + X₂ ≤ 16 ، X₁ + 2X₂ ≤ 11 ، X₁ + 3X₂ ≤ 15.
الحل الأمثل: **X₁ = 7، X₂ = 2، S₃ = 2، Z = 310**.

| B.V. | X₁ | X₂ | S₁ | S₂ | S₃ | B |
|---|---|---|---|---|---|---|
| S₃ | 0 | 0 | 1/3 | −5/3 | 1 | 2 |
| X₁ | 1 | 0 | 2/3 | −1/3 | 0 | 7 |
| X₂ | 0 | 1 | −1/3 | 2/3 | 0 | 2 |
| Z | 0 | 0 | 10/3 | 70/3 | 0 | 310 |

**القاعدة:** الحل الجديد = **B⁻¹ × b_new** (حيث B⁻¹ = أعمدة S₁, S₂, S₃ في الجدول الأمثل). لو **كل القيم الجديدة ≥ 0** يبقى نفس الـ basis ما زال ممكنًا (optimal).

**لو الـ RHS الأولاني اتغير من (16, 11, 15) لـ (20, 11, 15):**
```
[S3]   [ 1/3 -5/3 1] [20]   [20/3 - 55/3 + 15]   [10/3]
[X1] = [ 2/3 -1/3 0] [11] = [40/3 - 11/3     ] = [29/3]
[X2]   [-1/3  2/3 0] [15]   [-20/3 + 22/3    ]   [ 2/3]
Z = 30(29/3) + 50(2/3) = 323.33
```
> [!EXAMPLE]
> بعد الزيادة: **X₁ = 29/3، X₂ = 2/3، S₃ = 10/3، Z = 323.33** (كلها ≥ 0 فالـ basis سليم). **زيادة Z = 13.33 = 4 × (10/3)** يعني **shadow price (dual value) للقيد الأول = 10/3** لكل وحدة زيادة.

```python
# تحقق
from fractions import Fraction as F
Binv=[[F(1,3),F(-5,3),1],[F(2,3),F(-1,3),0],[F(-1,3),F(2,3),0]]
b=[20,11,15]; x=[sum(r[i]*b[i] for i in range(3)) for r in Binv]
print(x, 30*x[1]+50*x[2])   # [10/3, 29/3, 2/3]  970/3 = 323.33
```

## 4. مهمة: Chairs & Tables (Construct the model, solve graphically and by simplex)

> مصنع بينتج **كراسي (chairs)** و **ترابيزات (tables)**: ربح الكرسي **40\$** والترابيزة **50\$**.
> الكرسي: **2** ساعة عمل (man-hours)، **3** ساعة ماكينة، **1** وحدة خشب. الترابيزة: **2** ساعة عمل، **1** ساعة ماكينة، **4** وحدات خشب.
> المتاح يوميًا: **60** ساعة عمل، **75** ساعة ماكينة، **84** وحدة خشب. المطلوب: توزيع الموارد لتعظيم الربح.

**الموديل:** x₁ = كراسي، x₂ = ترابيزات.
```
Max Z = 40 x1 + 50 x2
s.t.  2x1 + 2x2 <= 60     (man-hours)
      3x1 +  x2 <= 75     (machine-hours)
       x1 + 4x2 <= 84     (wood)
      x1, x2 >= 0
```

**الحل البياني (corner points):** (0,0) → 0 · (25, 0) → 1000 · (22.5, 7.5) → 1275 · **(12, 18) → 1380** · (0, 21) → 1050. ⇒ **الأمثل = (12, 18)، Z = 1380**.

**السمبلكس:**

| Iter | Basic | x₁ | x₂ | s₁ | s₂ | s₃ | RHS |
|---|---|---|---|---|---|---|---|
| 0 | z | −40 | **−50** | 0 | 0 | 0 | 0 |
| | s₁ | 2 | 2 | 1 | 0 | 0 | 60 |
| | s₂ | 3 | 1 | 0 | 1 | 0 | 75 |
| | s₃ | 1 | 4 | 0 | 0 | 1 | 84 |
| 1 (x₂ enters, s₃ leaves: 84/4 = 21 الأصغر) | z | **−55/2** | 0 | 0 | 0 | 25/2 | 1050 |
| | s₁ | 3/2 | 0 | 1 | 0 | −1/2 | 18 |
| | s₂ | 11/4 | 0 | 0 | 1 | −1/4 | 54 |
| | x₂ | 1/4 | 1 | 0 | 0 | 1/4 | 21 |
| 2 (x₁ enters, s₁ leaves: 18/(3/2) = 12) | z | 0 | 0 | 55/3 | 0 | 10/3 | **1380** |
| | x₁ | 1 | 0 | 2/3 | 0 | −1/3 | **12** |
| | s₂ | 0 | 0 | −11/6 | 1 | 2/3 | 21 |
| | x₂ | 0 | 1 | −1/6 | 0 | 1/3 | **18** |

> [!EXAMPLE]
> **12 كرسي و 18 ترابيزة ⇒ ربح 1380\$**. الموارد: العمل 2(12)+2(18) = 60 ✓ (مستنفد) · الخشب 12+72 = 84 ✓ (مستنفد) · الماكينة 36+18 = 54 من 75 ⇒ **slack = 21** (s₂).
> **Shadow prices:** العمل = **55/3 ≈ 18.33\$/ساعة**، الخشب = **10/3 ≈ 3.33\$/وحدة**، الماكينة = 0.

> [!EXAM]
> - **Degenerate** = tie في ratio test · **Alt optima** = معامل 0 لـ non-basic · **Unbounded** = عمود ≤ 0 · **Infeasible** = artificial > 0.
> - **Dual:** Max↔Min · c↔b · القيود↔المتغيرات · transpose.
> - **Sensitivity للـ RHS:** x_new = B⁻¹ b_new (لازم ≥ 0).
