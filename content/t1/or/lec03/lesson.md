# الحل البياني وطريقة السمبلكس — Lecture 3: Graphical Method & Simplex Method (Reddy Mikks)

> [!NOTE]
> المحاضرة دي بتحل مثال **Reddy Mikks** بالطريقتين: **الطريقة البيانية (Graphical)** وبعدين **طريقة السمبلكس (Simplex)** بجداول (tableaus) خطوة بخطوة.

## 1. المثال 2.1-1: The Reddy Mikks Company

الشركة بتنتج **دهانات داخلية (interior)** و**خارجية (exterior)** من خامتين **M1** و **M2**:

| | Exterior paint | Interior paint | الحد الأقصى اليومي (طن) |
|---|---|---|---|
| Raw material **M1** | 6 | 4 | **24** |
| Raw material **M2** | 1 | 2 | **6** |
| Profit per ton ($1000) | **5** | **4** | |

**شروط إضافية:**
- طلب الـ interior اليومي **ما يزيدش** عن الـ exterior بأكتر من **1 طن**.
- أقصى طلب يومي للـ interior = **2 طن**.

### الموديل الرياضي
- x₁ = طن الـ **exterior** يوميًا، x₂ = طن الـ **interior** يوميًا. Z = الربح اليومي (بالألف $).

```
Maximize Z = 5 x1 + 4 x2
s.t.  6 x1 + 4 x2 <= 24     (raw material M1)
        x1 + 2 x2 <= 6      (raw material M2)
       -x1 +   x2 <= 1      (x2 - x1 <= 1 : market limit)
               x2 <= 2      (demand limit)
        x1, x2 >= 0
```

## 2. الطريقة البيانية — Graphical Method

**Step 1: تحديد الـ solution space**
1. حوّل كل قيد لمعادلة (بنستبدل ≤ بـ =) واحسب نقطتين لكل خط.
2. ارسم الخطوط (و x₁ = 0 و x₂ = 0) وحدد الجانب الممكن لكل قيد.

![شكل 1: الـ feasible space لموديل Reddy Mikks](img/or/lec03/feasible.webp)

**Step 2: إيجاد الحل الأمثل**

> الحل الأمثل لأي LP **دايمًا مرتبط بـ corner point** من الـ solution space، فنقدر نعدد كل الـ corner points:

| Corner | (x₁, x₂) | Z |
|---|---|---|
| A | (0, 0) | 0 |
| B | (4, 0) | 20 |
| **C** | **(3, 1.5)** | **21** ← **optimum** |
| D | (2, 2) | 18 |
| E | (1, 2) | 13 |
| F | (0, 1) | 4 |

![شكل 2: الحل الأمثل لموديل Reddy Mikks](img/or/lec03/optimal.webp)

> [!EXAMPLE]
> **x₁ = 3 طن، x₂ = 1.5 طن، Z = 21 (= 21,000$)**. (التحقق: M1: 6×3+4×1.5 = 24 ✓ · M2: 3+2×1.5 = 6 ✓.)

> [!WARNING]
> عدد الـ corner points **بيزيد** مع زيادة المتغيرات والقيود، ومن هنا جاءت الحاجة لـ **simplex**.

## 3. طريقة السمبلكس — Simplex Method

### 3.1 الصيغة القياسية (Standard form)
بنضيف **slack variable** لكل قيد ≤ (s₁ ... s₄):

```
Maximize z = 5x1 + 4x2 + 0s1 + 0s2 + 0s3 + 0s4
 6x1 + 4x2 + s1                = 24    (raw material M1)
  x1 + 2x2      + s2           = 6     (raw material M2)
 -x1 +  x2           + s3      = 1     (market limit)
        x2                + s4 = 2     (demand limit)
 x1, x2, s1, s2, s3, s4 >= 0
```

ودالة الهدف بتتكتب: **z − 5x₁ − 4x₂ = 0**. الحل الابتدائي: x₁ = x₂ = 0، **الـ basic variables = s₁..s₄**.

### 3.2 قواعد السمبلكس (للـ Max)

| القاعدة | الوصف |
|---|---|
| **Entering variable** | المتغير اللي **معامله في صف z الأكثر سالبية** |
| **Leaving variable** | بـ **minimum ratio test**: نقسم **RHS ÷ معامل الـ entering** للقيم **الموجبة** بس (أصغر نسبة). (القسمة على سالب أو صفر **بتتتجاهل**) |
| **Pivot row** | صف الـ leaving variable، نقسمه على **pivot element** |
| **باقي الصفوف (z كمان)** | **New row = Current row − (pivot column coefficient) × New pivot row** |
| **التوقف (Optimality)** | لما **كل معاملات صف z ≥ 0** |

### 3.3 Iteration 0 (Initial)

| Basic | x₁ | x₂ | s₁ | s₂ | s₃ | s₄ | RHS |
|---|---|---|---|---|---|---|---|
| **z** | **−5** | −4 | 0 | 0 | 0 | 0 | 0 |
| s₁ | 6 | 4 | 1 | 0 | 0 | 0 | 24 |
| s₂ | 1 | 2 | 0 | 1 | 0 | 0 | 6 |
| s₃ | −1 | 1 | 0 | 0 | 1 | 0 | 1 |
| s₄ | 0 | 1 | 0 | 0 | 0 | 1 | 2 |

- **Entering = x₁** (أكبر سالب −5).
- **النسب:** s₁: 24/6 = **4** (الأصغر) · s₂: 6/1 = 6 · s₃: 1/(−1) سالب **تتجاهل** · s₄: 0 في العمود **تتجاهل**. ⇒ **Leaving = s₁**.

### 3.4 Iteration 1
بنقسم صف s₁ على 6 (الـ pivot) فيبقى صف x₁: (1, 2/3, 1/6, 0, 0, 0 | 4). وباقي الصفوف بالقاعدة:

| Basic | x₁ | x₂ | s₁ | s₂ | s₃ | s₄ | RHS |
|---|---|---|---|---|---|---|---|
| **z** | 0 | **−2/3** | 5/6 | 0 | 0 | 0 | 20 |
| **x₁** | 1 | 2/3 | 1/6 | 0 | 0 | 0 | 4 |
| s₂ | 0 | 4/3 | −1/6 | 1 | 0 | 0 | 2 |
| s₃ | 0 | 5/3 | 1/6 | 0 | 1 | 0 | 5 |
| s₄ | 0 | 1 | 0 | 0 | 0 | 1 | 2 |

- **Entering = x₂** (−2/3). النسب: x₁: 4/(2/3) = 6 · **s₂: 2/(4/3) = 1.5** (الأصغر) · s₃: 5/(5/3) = 3 · s₄: 2/1 = 2. ⇒ **Leaving = s₂**.

### 3.5 Iteration 2 (Optimal)

| Basic | x₁ | x₂ | s₁ | s₂ | s₃ | s₄ | RHS |
|---|---|---|---|---|---|---|---|
| **z** | 0 | 0 | **3/4** | **1/2** | 0 | 0 | **21** |
| **x₁** | 1 | 0 | 1/4 | −1/2 | 0 | 0 | **3** |
| **x₂** | 0 | 1 | −1/8 | 3/4 | 0 | 0 | **3/2** |
| s₃ | 0 | 0 | 3/8 | −5/4 | 1 | 0 | 5/2 |
| s₄ | 0 | 0 | 1/8 | −3/4 | 0 | 1 | 1/2 |

> [!EXAMPLE]
> كل معاملات صف z **≥ 0** ⇒ **Optimal**: **x₁ = 3، x₂ = 3/2، z = 21**. والـ slacks: s₃ = 5/2 و s₄ = 1/2 (قيدين مش binding).

> [!NOTE]
> جداول السمبلكس دي اتولدت وراجعتها بحساب بالكسور (Python) ومطابقة لجدول السلايد الأخير. وتفسير: **السمبلكس بيتحرك من corner point لـ corner point مجاور** (الأصل (0,0) ← B(4,0) ← C(3,1.5)) وكل خطوة بتحسّن z: 0 → 20 → 21.

```
Path of simplex:  A(0,0) z=0  ->  B(4,0) z=20  ->  C(3, 1.5) z=21 (optimal)
```

> [!EXAM]
> - **Entering:** أكتر قيمة سالبة في صف z · **Leaving:** أصغر نسبة موجبة (RHS ÷ pivot column).
> - **Optimal** لما كل معاملات z ≥ 0.
> - Reddy Mikks: **(3, 1.5) ⇒ z = 21**.
