# سكريبت الفيديو الإعلاني — مذاكرة IS (آي إس) (حوالي 60 ثانية)

## 🎙 النص للـ Voice Over (ElevenLabs — Multilingual v2)
> انسخ النص ده زي ما هو. كل فقرة = مشهد. سيب سطر فاضي بين الفقرات عشان يبقى فيه نَفَس بسيط بينهم.

امتحاناتك قرّبت، والمحاضرات كتير، ومش عارف تبدأ منين؟

مع "مذاكرة آي إس"، هتلاقي المواد العامة ومواد قسم آي إس في مكان واحد. اتنين وستين محاضرة وسكشن، متشرحين بالمصري وببساطة. وباقي المواد نازلة قريب.

كل محاضرة متشرحة خطوة بخطوة، بالجداول والرسومات وصور السلايدات، ومعاها ملخص سريع لليلة الامتحان.

وبعد ما تذاكر، امتحن نفسك. أكتر من ألف وتسعمية سؤال، وكل سؤال معاه شرح للإجابة الصح. والأسئلة اللي غلطت فيها بتتجمعلك لوحدها، عشان تراجعها قبل الامتحان.

وكمان فيه مراجعة للميد تيرم والفاينال، بامتحان بتايمر، وأكتر من تسعمية كارت للحفظ السريع.

وفي بحوث العمليات، تقدر تحل مسائل السيمبلكس والنقل والتخصيص، خطوة بخطوة، جوه الأبلكيشن نفسه.

سجّل بالإيميل، ومذاكرتك هتفضل محفوظة على أي جهاز، موبايل أو لابتوب، وتابع مستواك في كل مادة.

مذاكرة آي إس... ذاكر صح، مش كتير. وابعت دلوقتي لباشمهندس سيف، عشان يفعّلك الأبلكيشن.

## 🔤 الكلمات اللي اتعدّلت عشان النطق
| قبل | بعد | ليه |
|---|---|---|
| IS | آي إس | الحروف الإنجليزي لوحدها ممكن تتقري "إز" أو تتنطق إنجليزي بلكنة غريبة |
| ست مواد | المواد العامة ومواد قسم آي إس + "وباقي المواد نازلة قريب" | يوضّح المتاح دلوقتي (OS · Networks · OR + IS · Storage · SAD) والباقي جاي |
| تقدّمك بيتحفظ | مذاكرتك هتفضل محفوظة | "تقدمك" ممكن تتقري "تقدِّملك" (من التقديم) |
| السمبلكس | السيمبلكس | الياء بتضمن إنها تتنطق "سيم" مش "سَمْ" |
| الميد | الميد تيرم | "الميد" لوحدها ممكن تتقري "المِيد" بمعنى تاني |
| بامتحان بوقت | بامتحان بتايمر | أوضح ومصري أكتر |
| اختبر نفسك | امتحن نفسك | أقرب للعامية |
| بمنتهى البساطة | ببساطة | أقصر وأقل فصحى |
| ذاكر أذكى، مش أكتر | ذاكر صح، مش كتير | "أكتر/أذكى" ورا بعض بيلخبطوا النبرة، والجديدة أسهل وأوضح |

| الأرقام | مكتوبة بالحروف (اتنين وستين، ألف وتسعمية، تسعمية) | عشان ميقراهاش بالفصحى أو بالإنجليزي |
